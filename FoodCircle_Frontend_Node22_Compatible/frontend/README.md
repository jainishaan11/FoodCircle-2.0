# FoodCircle Frontend

React 19 frontend built with Vite 6.4.5 and `@vitejs/plugin-react` 4.7.0.

## Local development

```bash
npm install --include=optional --package-lock=false
npm run dev
```

## Production build

```bash
npm install --include=optional --package-lock=false
npm run build
```

The production static files are written to `dist/`. See `README_N8N_DEPLOYMENT.md` for the n8n API configuration and Selfhost.dev deployment details.
